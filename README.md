## 📦 onekey-suoha 一键梭哈脚本

onekey-suoha 是一个用于在 Linux 系统上一键部署 Xray + Cloudflared 通过 Cloudflare Argo / Tunnel 快捷生成科学上网（V2Ray / VLESS）链接的 Bash 脚本。
该脚本自动检测系统、安装必要依赖、下载 Xray 和 cloudflared，并根据选择的模式创建或管理梭哈隧道（快速隧道 / 长期服务隧道）。

## 📥 安装与运行：
```
curl https://raw.githubusercontent.com/Filterrr/suoha.sh/main/suoha.sh -o suoha.sh && bash suoha.sh
```
