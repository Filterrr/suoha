## 📦 onekey-suoha 一键梭哈脚本

suoha 是一键部署 Xray + Cloudflared 通过 Cloudflare Argo / Tunnel 一键生成带有TLS加密的科学上网（V2Ray / VLESS）链接。
该脚本自动检测系统、安装必要依赖、下载 Xray 和 cloudflared，并根据选择的模式创建suoha隧道（快速隧道 / 长期服务隧道）。

## 📥 安装与运行：
```
curl https://raw.githubusercontent.com/Filterrr/suoha.sh/main/suoha.sh -o suoha.sh && bash suoha.sh
```
